개인정보 처리방침

시행일: 2026년 7월 12일 · "Teams Message Extractor — Chat Export" 브라우저 확장 프로그램에 적용됩니다

요약: 확장 프로그램의 모든 동작은 브라우저 내에서 로컬로 수행됩니다. Teams 메시지, 파일 및 내보내기 결과는 사용자의 기기를 떠나지 않습니다. 당사는 어떠한 분석 데이터도 수집하지 않고, 서버를 운영하지 않으며, 사용자의 데이터를 볼 수 없습니다.

확장 프로그램이 데이터를 처리하는 방식

추출을 시작하면 확장 프로그램은 브라우저 탭에 열려 있는 Microsoft Teams 대화를 읽고, 내보내기 결과물(CSV, HTML 또는 첨부 파일 ZIP)을 전적으로 사용자의 기기에서 생성합니다. 생성된 파일은 브라우저의 일반 다운로드 기능을 통해 컴퓨터에 저장됩니다. 메시지 내용은 확장 프로그램 개발자나 제3자에게 절대 전송되지 않습니다.

저장되는 항목과 저장 위치

  • 설정(언어 기본 설정, 스크롤 지연, 내보내기 옵션)은 브라우저의 로컬 확장 프로그램 저장소에 저장됩니다.
  • 추출 결과는 팝업을 닫았다가 다시 열어도 상태를 복원할 수 있도록 세션 저장소에 임시로 보관됩니다. 30분 후 또는 탭을 닫으면 자동으로 삭제됩니다.
  • 최초 설치 타임스탬프는 향후 유료 등급이 출시될 경우 장기 사용자를 얼리 서포터 할인 대상으로 인식할 수 있도록 로컬에 저장됩니다. 이 정보는 사용자의 기기를 떠나지 않습니다.

수집하지 않는 항목

  • 어떠한 종류의 분석 또는 원격 측정도 수집하지 않습니다
  • 계정, 가입 또는 개인 정보를 요구하지 않습니다
  • 메시지 내용, 파일 내용, 연락처 이름 또는 메타데이터를 어디로도 전송하지 않습니다
  • 쿠키, 핑거프린팅, 광고 식별자를 사용하지 않습니다

확장 프로그램이 권한을 요청하는 이유

  • Teams 도메인(teams.microsoft.com, teams.live.com, teams.cloud.microsoft) — 열려 있는 대화를 읽어 내보내기 위해 필요합니다.
  • SharePoint / OneDrive / Teams 미디어 호스트(sharepoint.com, 1drv.ms, asm.skype.com 및 관련 호스트) — 기존 로그인 세션을 사용하여 채팅에 표시되는 첨부 파일과 이미지를 다운로드하기 위해 필요합니다. 이 다운로드는 Microsoft 서버에서 사용자의 기기로 직접 전송됩니다.
  • 저장소 — 위에 나열한 설정과 임시 상태를 저장하기 위해 필요합니다.
  • 다운로드 — 내보내기 결과를 컴퓨터에 저장하기 위해 필요합니다.

향후 유료 기능

향후 업데이트에서 유료 등급이 도입될 예정입니다(유료 모델 FAQ 참조). 출시될 경우, 라이선스를 활성화하면 라이선스 키와 무작위로 생성된 익명 설치 식별자만 결제 및 라이선스 제공업체인 Lemon Squeezy로 전송되어 라이선스를 검증합니다. 결제 정보는 전적으로 Lemon Squeezy가 자체 개인정보 처리방침에 따라 처리하며, 확장 프로그램은 결제 정보를 볼 수 없습니다. Teams 메시지 내용은 계속해서 사용자의 기기에서만 처리됩니다. 이러한 변경이 시행되기 전에 본 방침이 먼저 업데이트됩니다.
