Teams Message Extractor - Chat Export

모든 처리는 브라우저 안에서 이루어집니다. 메시지와 파일은 사용자의 기기에서 로컬로 처리되며, 당사나 제3자 서버로 전송되지 않습니다. 자세한 내용은 개인정보 처리방침을 참조하십시오.

Microsoft Teams 채팅 메시지, 파일, 이미지, 이모지 반응을 CSV 또는 HTML로 내보냅니다. 완전한 백업과 보관을 위해 전체 채팅 기록을 자동으로 스크롤하며, 첨부 파일은 단일 ZIP으로 묶어 저장합니다.

Teams Message Extractor는 첫 메시지부터 최신 메시지까지 전체 대화 기록을 자동으로 스크롤하여, 모든 내용을 깔끔하게 구조화된 CSV 파일 또는 독립형 HTML 기록으로 내보냅니다. 첨부 파일은 저장 대화상자가 수십 번 뜨는 대신 단일 ZIP 아카이브로 한 번에 다운로드됩니다. 1:1 메시지, 그룹 채팅, 채널을 지원하며 세 개의 Teams 도메인(teams.microsoft.com, teams.live.com, teams.cloud.microsoft) 모두에서 작동합니다.

2.9.0의 새로운 기능

  • 새 기능: 채널 게시물 추출. 스레드 대화를 제목과 스레드 구조를 포함해 중첩된 모든 답글과 함께 내보냅니다.
  • 새로운 Markdown 내보내기. 메모, 위키, AI 도구에 붙여넣기에 적합합니다.
  • CSV 내보내기가 이제 Excel에서 올바르게 열려, 한글과 악센트 문자가 더 이상 깨지지 않습니다.
  • 붙여넣은 이미지와 스크린샷을 안정적으로 캡처하며, 이전에 자주 누락되던 새 teams.cloud.microsoft 레이아웃에서도 지원합니다.
  • 스크린샷이 HTML 기록에 직접 삽입되어, 이미지가 링크가 아닌 인라인으로 내보내기 안에 표시됩니다.
  • 원본 이미지 품질을 그대로 유지하여, 첨부 파일이 재압축 없이 원본 파일 그대로 저장됩니다.

캡처되는 항목

  • 발신자 이름과 타임스탬프
  • 전체 메시지 내용
  • 이모지 반응(메시지별, 개수 포함)
  • 첨부 파일, 이미지 및 URL
  • 전체 대화 스레드

사용 방법

  1. 브라우저에서 Teams 대화를 엽니다
  2. 확장 프로그램 아이콘을 클릭합니다
  3. 확장 프로그램이 채팅의 맨 처음까지 자동으로 스크롤하며 모든 메시지를 캡처합니다
  4. CSV, HTML 또는 묶은 ZIP 아카이브로 다운로드합니다

이런 용도에 적합

  • 중요한 대화가 사라지기 전에 보관
  • 컴플라이언스 및 감사 요건 대응
  • 오래된 채팅 기록의 오프라인 검색
  • 프로젝트 논의와 결정 사항 백업
  • 데이터 마이그레이션 또는 기록 작성
  • HR 및 법무 문서화 요건 대응

주요 기능

  • 전체 자동 스크롤로 채팅 기록 전체를 자동 캡처하므로 수동 스크롤이 필요 없습니다
  • 1:1 메시지, 그룹 채팅, 채널은 물론 세 개의 Teams 도메인 어디서나 작동합니다
  • 스프레드시트용 CSV와, 반응 및 클릭 가능한 첨부 링크가 담긴 서식 있는 HTML 기록 등 여러 형식으로 내보낼 수 있습니다
  • 모든 첨부 파일을 하나의 스트리밍 ZIP으로 다운로드하며, 4 GB가 넘는 아카이브를 위한 ZIP64와 텍스트 파일용 DEFLATE 압축을 지원합니다
  • 이모지 반응을 메시지별로 캡처하여 CSV와 HTML에 모두 표시합니다
  • 팝업을 닫아도 ZIP 다운로드가 백그라운드에서 계속 디스크로 저장됩니다
  • 개인정보를 최우선으로 하여 모든 처리를 브라우저 안에서 로컬로 수행하며, 외부 서버로 데이터를 전송하지 않습니다
  • 18개 언어를 지원하며, 아랍어와 우르두어는 오른쪽에서 왼쪽 레이아웃으로 표시됩니다
  • 가볍고 빠릅니다
