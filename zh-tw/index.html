Teams Message Extractor - Chat Export

所有處理都在您的瀏覽器中完成。您的訊息和檔案均在您的裝置上本機處理，絕不會傳送給我們或任何第三方伺服器。詳情請參閱隱私權政策。

將 Microsoft Teams 的聊天訊息、檔案、圖片和表情回應匯出為 CSV 或 HTML。自動捲動完整的聊天記錄，進行完整備份與封存，並將附件打包為單一 ZIP。

Teams Message Extractor 會自動捲動您的整個對話記錄，從最早的訊息到最新的訊息，並將所有內容匯出為結構清晰的 CSV 檔案或獨立的 HTML 記錄檔。附件會打包成單一 ZIP 壓縮檔下載，不必一一處理數十個儲存對話框。支援私訊、群組聊天和頻道，並相容於三個 Teams 網域（teams.microsoft.com、teams.live.com、teams.cloud.microsoft）。

2.9.0 新功能

  • 新增：頻道貼文擷取。討論串會話匯出時包含所有巢狀回覆、主旨與討論串結構。
  • 新增 Markdown 匯出，適合貼到筆記、Wiki 或 AI 工具中。
  • CSV 匯出檔現在可在 Excel 中正確開啟，中文及帶重音符號的字元不再顯示為亂碼。
  • 貼上的圖片和螢幕擷取畫面現在都能穩定擷取，包括先前經常遺漏的新版 teams.cloud.microsoft 介面。
  • 螢幕擷取畫面會直接嵌入 HTML 記錄檔，圖片在匯出結果中以內嵌方式顯示，而不只是連結。
  • 保留原始圖片品質：附件以一模一樣的原始檔案儲存，不會重新壓縮。

擷取內容

  • 傳送者姓名與時間戳記
  • 完整訊息內容
  • 表情回應（依訊息計數）
  • 附件、圖片及其 URL
  • 完整對話串

使用方法

  1. 在瀏覽器中開啟任何 Teams 對話
  2. 點擊擴充功能圖示
  3. 擴充功能會自動捲動到聊天開頭，擷取每一則訊息
  4. 下載為 CSV、HTML 或打包的 ZIP

適用情境

  • 在重要對話遺失前進行封存
  • 合規與稽核需求
  • 離線搜尋舊有聊天記錄
  • 備份專案討論與決策
  • 資料移轉或建立記錄
  • 人資與法律文件需求

主要功能

  • 完整自動捲動：自動擷取整個聊天記錄，無需手動捲動
  • 全面支援 Teams：私訊、群組聊天、頻道，以及全部三個 Teams 網域
  • 多種匯出格式：CSV 適合試算表使用，HTML 則是含表情回應與可點擊附件連結的格式化記錄檔
  • 串流 ZIP 下載：所有附件打包成單一檔案，支援 ZIP64 可處理超過 4 GB 的封存檔，文字檔並採用 DEFLATE 壓縮
  • 表情回應：逐則訊息擷取，並顯示在 CSV 與 HTML 輸出中
  • 下載不受彈出視窗影響：關閉彈出視窗後，ZIP 仍會在背景繼續串流寫入磁碟
  • 隱私優先：所有處理都在瀏覽器本機完成，不會將資料傳送到外部伺服器
  • 支援 20 種語言，阿拉伯文與烏都語支援由右至左排版
  • 輕量且快速
