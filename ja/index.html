Teams Message Extractor — Chat Export

すべての処理はブラウザ内で行われます。メッセージとファイルはお使いのデバイス上でローカルに処理され、当社や第三者のサーバーに送信されることは一切ありません。詳細はプライバシーポリシーをご覧ください。

Microsoft Teams のチャットメッセージ、ファイル、画像、絵文字リアクションを CSV または HTML にエクスポート。完全なバックアップとアーカイブのためにチャット履歴全体を自動スクロール — 添付ファイルは単一の ZIP にまとめられます。

Teams Message Extractor は会話履歴全体を最初のメッセージから最新のものまで自動的にスクロールし、すべてを整理された構造化 CSV ファイルまたは自己完結型の HTML トランスクリプトとしてエクスポートします。添付ファイルは数十の保存ダイアログではなく、単一の ZIP アーカイブとしてダウンロードされます。ダイレクトメッセージ、グループチャット、チャネルに対応し、3 つの Teams ドメイン (teams.microsoft.com、teams.live.com、teams.cloud.microsoft) すべてで動作します。

2.8.1 の新機能

  • CSV エクスポートが Excel で正しく開けるようになりました — 日本語やアクセント付き文字が文字化けしなくなりました。
  • 貼り付けた画像とスクリーンショットを確実にキャプチャ — 以前は多くが取りこぼされていた新しい teams.cloud.microsoft のレイアウトでも対応。
  • スクリーンショットを HTML トランスクリプトに直接埋め込み — 画像はリンクではなくエクスポート内にインラインで表示されます。
  • 元の画質を維持 — 添付ファイルは再圧縮せず、元のファイルそのままで保存されます。

キャプチャされる内容

  • 送信者名とタイムスタンプ
  • メッセージ全文
  • 絵文字リアクション (メッセージごと、件数付き)
  • 添付ファイル、画像、およびそれらの URL
  • 完全な会話スレッド

使い方

  1. ブラウザで Teams の会話を開く
  2. 拡張機能のアイコンをクリック
  3. 拡張機能がチャットの先頭まで自動スクロールし、すべてのメッセージをキャプチャ
  4. CSV、HTML、またはまとめられた ZIP アーカイブとしてダウンロード

こんな用途に最適

  • 失われる前に重要な会話をアーカイブ
  • コンプライアンスと監査要件
  • 古いチャット履歴をオフラインで検索
  • プロジェクトの議論と決定事項のバックアップ
  • データ移行や記録作成
  • 人事・法務のドキュメント作成

主な機能

  • 完全な自動スクロール — チャット履歴全体を自動的にキャプチャ、手動スクロール不要
  • Teams のあらゆる場所で動作 — ダイレクトメッセージ、グループチャット、チャネル、3 つのすべての Teams ドメイン
  • 複数のエクスポート形式 — スプレッドシート用の CSV、リアクションとクリック可能な添付リンク付きの整形された HTML トランスクリプト
  • ストリーミング ZIP ダウンロード — すべての添付を 1 つのアーカイブに、4 GB を超えるアーカイブに対応する ZIP64 とテキストファイルの DEFLATE 圧縮をサポート
  • 絵文字リアクション — メッセージごとにキャプチャされ、CSV と HTML の両方に表示
  • ポップアップに依存しないダウンロード — ポップアップを閉じても ZIP はバックグラウンドでディスクへのストリーミングを継続
  • プライバシー重視 — すべての処理はブラウザ内でローカルに行われ、外部サーバーには一切データを送信しません
  • 20 言語に対応、アラビア語とウルドゥー語は右から左へのレイアウトをサポート
  • 軽量かつ高速
